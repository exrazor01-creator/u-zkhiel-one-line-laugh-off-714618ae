## The entry

80 characters, one line, plain ASCII — inside the 1–200 character gate.

## Why this line

Written against the judge's brief, in the order it weighs things:

1. **Genuinely funny on a cold read** — a wellness purchase that changes nothing about the owner.
2. **The laugh lands suddenly** — the twist arrives in the last three words, "at a higher altitude".
3. **Surprise** — the reader expects a health win and gets the same bad habit, just taller.
4. **Economy** — 80 characters, every word earning its place, nothing left to trim. A second edit cut "stand still": it only restated the standing desk and delayed the punchline, so the same joke now lands sooner.
5. **Fresh** — not a gym joke or a diet joke: the furniture itself is the punchline.
